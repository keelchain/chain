# Keel brand assets

- `keel-mark.svg` — the mark: a hull over its keel, on the deep-sea square. Square, any size.
- `keel-logo.svg` — mark + wordmark "keelchain" for light backgrounds; `keel-logo-dark.svg` for dark.
- `favicon.svg` — the mark at favicon size.

Colours: deep sea `#0F2F5B` → `#081C36`, hull teal `#2DD4BF`, keel gold `#F5C451`, ink `#0F2F5B`, paper `#F8FAFC`.
Wordmark: Inter Bold (fallback Helvetica/Arial), tracking −1. Names: **Keel** (brand), **Keelchain** (network), `KEEL` (native asset), `KUSD` (stablecoin). Domains: keelchain.com (site, wallet pages), testnet.keelchain.com (explorer, API, RPC).
