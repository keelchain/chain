# @keelchain/sdk

TypeScript client for the Keelchain.

```ts
import { Keypair, RpcClient } from "@keelchain/sdk";
const rpc = new RpcClient("http://127.0.0.1:5000");
const key = Keypair.fromSecret(process.env.KEEL_SECRET!);       // 32-byte hex
const tx = await rpc.send(key, { Transfer: { to: "<hex address>", asset: "KUSD", amount: 5_000_000n } });
const receipt = await rpc.waitReceipt(tx);
```

- Actions are written in the node's JSON form (the Rust serde shape,
  see `src/actions.ts`); the SDK borsh-encodes them exactly as the chain
  does and signs `sha256("keel-action-v1" || borsh(envelope))` with ed25519.
- Amounts are `bigint` (smallest units); numbers/strings are accepted.
- `test/vectors.json` is generated by `cargo test -p keel-actions` and pins
  every encoding byte for byte: regenerate it whenever `action.rs` changes.

Scripts: `npm test`, `npm run build`, `KEEL_RPC=... npm run example`.
